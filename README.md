# 🔒 Tela de Login Moderna

Uma interface de login moderna, responsiva e interativa desenvolvida com **HTML5**, **CSS3** e **JavaScript Vanilla**. Conta com validações em tempo real, alternância de visibilidade da senha e simulação de estado de carregamento.

---

## 🚀 Funcionalidades

- **🎨 Design Moderno e Responsivo**: Totalmente adaptável para celulares e computadores com layout centralizado via Flexbox.
- **🛡️ Validação em Tempo Real (Inline Errors)**:
  - Validação de formato de e-mail utilizando Expressão Regular (Regex).
  - Verificação de tamanho mínimo de senha (mínimo de 6 caracteres).
  - Destaque com borda vermelha e mensagens explicativas na própria tela (sem uso de `alert`).
  - Remoção instantânea dos erros enquanto o usuário digita para corrigir.
- **👁️ Mostrar / Ocultar Senha**: Botão interativo para alternar a visibilidade da senha entre oculta e visível.
- **⏳ Estado de Carregamento (*Loading*)**: Desabilita o botão e altera o texto para *"Entrando..."*, simulando uma requisição de autenticação real.
- **🎉 Feedback de Sucesso**: Exibe mensagem amigável de confirmação e limpa os campos automaticamente.
